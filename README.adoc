= Equivalence Rules: Filesystem

Cross-OS filesystem path equivalency rules (Linux, Windows, macOS, BSD) for the Evolution Engine.

link:https://github.com/dev-centr/equivalence-engine[Equivalence Engine] ·
link:https://github.com/dev-centr/equivalence-rules-filesystem/issues[Report Bug] ·
link:https://github.com/dev-centr/equivalence-rules-filesystem/issues[Request Feature]

== About The Project

Cross-OS filesystem path equivalency rules (Linux, Windows, macOS, BSD) for the link:https://github.com/dev-centr/equivalence-engine[Equivalence Engine].

This repository is a **Content Repository** for the `filesystem` domain. It provides abstract "intents" (e.g., `lib_dir`, `config_dir`) and maps them to literal paths across different operating systems and distributions.

=== Ecosystem

* link:https://github.com/dev-centr/equivalence-engine[Equivalence Engine] — The core binary that resolves and applies these rules.
* link:https://github.com/dev-centr/equivalence-engine-action[Equivalence Engine Action] — Modular GitHub Action to automate code adaptation in CI pipelines.
* link:https://github.com/dev-centr/equivalence-rules-code[Equivalence Rules: Code] — Rules for migrating source code between library versions.
* link:https://github.com/dev-centr/equivalence-rules-filesystem[Equivalence Rules: Filesystem] — This repository.

=== Directory Structure

[source]
----
rules/
├── linux/              <-- OS Family
│   └── ubuntu/         <-- Distribution
│       └── 22.04/      <-- Version
├── windows/
└── mac/
----

== Usage

To resolve a filesystem intent across platforms:

[source,bash]
----
equivalence-engine --domain filesystem \
  --rules-repo https://github.com/dev-centr/equivalence-rules-filesystem \
  --to linux/ubuntu/22.04 lib_dir
----

== Contributing

Add new path mappings to the `rules/<os>/<distro>/<version>/` folders. Use the intent name as the filename (e.g., `rules/linux/ubuntu/lib_dir.sdl`).
